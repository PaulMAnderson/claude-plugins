# Astrolabe house style for Gemini CLI

This extension provides code, test, architecture, database, and technical-writing guidance. `GEMINI.md` gives the shared overview; individual skills live in `skills/`, including Python, MATLAB, R, MySQL, and functional-core guidance.

```sh
gemini extensions link /absolute/path/to/claude-plugins/gemini/extensions/astrolabe-house-style
```

Use the specific skill that matches the code or document under review. Project instructions and the user's requirements take precedence over style guidance.
