# Astrolabe extension authoring for Gemini CLI

This extension contains guidance for creating and maintaining assistant skills, agents, hooks, instructions, and plugin documentation. Its skill files are in `skills/`; `GEMINI.md` provides shared context, and `agents/project-claude-librarian.md` describes project instruction maintenance.

```sh
gemini extensions link /absolute/path/to/claude-plugins/gemini/extensions/astrolabe-extending-claude
```

Use the relevant skill when updating a component. For changes to Astrolabe tier behavior, follow the [three-distribution sync checklist](../../../docs/skill-sync-checklist.md).
