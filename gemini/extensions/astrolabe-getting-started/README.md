# Astrolabe getting started for Gemini CLI

This extension provides `/getting-started`, a short guide to the four Astrolabe tiers and their shared local project files.

```sh
gemini extensions link /absolute/path/to/claude-plugins/gemini/extensions/astrolabe-getting-started
```

After linking, run `/getting-started` in Gemini CLI. For installation and the full workflow, see the [root README](../../../README.md); for file formats, see the [state contract](../../../docs/astrolabe-state-format.md).
